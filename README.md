# LIFE-UP STYLE — 전체 한 벌

잘사는 사주로 업그레이드하는 앱 · Style up life app

이 폴더 안에 **사이트에 필요한 것이 전부** 들어 있습니다.
`_source/` 만 빼고 **그대로 저장소 맨 위(루트)에 올리시면** 됩니다.

---

# 1. 올리는 법

## 저장소에 이렇게 놓으세요

```
내-저장소/                     ← 여기가 사이트 루트
  index.html                   ← 앱 (자족형, 엔진·아이콘 전부 포함)
  terms.html                   ← 이용약관
  privacy.html                 ← 개인정보처리방침
  og.png                       ← 카카오톡·페이스북 미리보기
  favicon.ico  favicon.svg
  apple-touch-icon.png
  icon-192.png  icon-512.png
  site.webmanifest             ← 홈 화면에 추가용
  robots.txt  sitemap.xml
  vercel.json

  _source/                     ← 올리셔도 되고 안 올리셔도 됩니다
```

`_source/` 는 **나중에 고치실 때 쓰는 원본**입니다.
사이트 동작에는 필요 없으니 올리지 않으셔도 됩니다.
(저장소에 두시면 다음에 고칠 때 편합니다.)

## Vercel 설정

프레임워크 없는 정적 사이트입니다. **Settings → Build and Deployment** 에서

| 항목 | 값 |
|---|---|
| Framework Preset | **Other** |
| Build Command | **비우기** |
| Output Directory | **비우기** |
| Install Command | **비우기** |

**Settings → General → Root Directory** 는 **비어 있어야** 합니다.

> 지난번 404는 `index.html` 이 없어서였습니다. 이제 들어 있으니 `/` 로 열립니다.

# 2. 올리기 전에 반드시 바꿀 것

## ① 도메인 — 14곳

`REPLACE_WITH_DOMAIN` 을 실제 도메인으로 전부 바꾸세요.
편집기의 "전체 바꾸기"로 한 번에 하시면 됩니다.

| 파일 | 곳 |
|---|---|
| `index.html` | 6 |
| `sitemap.xml` | 4 |
| `robots.txt` | 2 |
| `terms.html` | 1 |
| `privacy.html` | 1 |

바꾸신 뒤 `https://내도메인/og.png` 가 직접 열리는지 꼭 확인하세요.
이게 안 열리면 카카오톡 미리보기가 안 뜹니다.

## ② 사업자 정보 — 20곳

`terms.html` 에 13곳, `privacy.html` 에 7곳이 <strong>○○</strong> 로 비어 있습니다.
화면에서 노란 배경으로 표시되니 눈으로 찾으실 수 있습니다.

상호 · 대표자 · 사업장 주소 · 사업자등록번호 · 통신판매업 신고번호 ·
전화 · 전자우편 · 개인정보보호책임자 · 호스팅 제공자 · 시행일

채우신 뒤 두 문서 맨 위의 **빨간 상자를 지우세요.** 안 지우면 손님에게 보입니다.

> 두 문서는 바로 쓰실 수 있게 만든 초안입니다.
> 결제를 받는 서비스이니, 여시기 전에 한 번은 전문가에게 확인받으시길 권합니다.

## ③ 테스트 모드 끄기

`index.html` 에서 찾아 바꾸세요.

```js
window.TEST_MODE = true;   →   window.TEST_MODE = false;
```

지금은 결제 없이 전부 열리는 상태입니다.

## ④ 토스페이먼츠

가맹 신청 후 받은 클라이언트 키를 `index.html` 의 결제 부분에 넣으세요.
상품코드는 이렇게 잡혀 있습니다.

## 만세력

절기 · 진태양시(경도 보정) · 그 시절 표준시 · 음력과 윤달 ·
십신 · 십이운성 · 공망 · **신살 32종** · 대운 · 세운

## 글의 원칙

- 전문 용어는 쓰되 **바로 옆에 쉬운 말**을 붙입니다 (용어 74개 사전)
- 방향을 제시하는 자리에는 **TIP** 으로 **그대로 따라 할 문구**를 답니다
  (사전 197개 키 / 394문장, 적용률 100%)
- 신년운세는 예측이 아니라 **처방**으로 끝납니다

# 4. 고치는 법

`_source/` 에서 고치고 다시 묶습니다.

```bash
cd _source
python3 build.py ../index.html
```

| 고치고 싶은 것 | 볼 파일 |
|---|---|
| 화면·CSS·결제 UI | `ui-manse.html` |
| 여섯 갈래 문구 | `report.js` · `manse.js` |
| 신년운세 (해의 이름, 달, 과제) | `newyear-copy.js` |
| 신년 꼭지 구성 | `newyear.js` |
| 세운·월운 계산 | `newyear-core.js` |
| 궁합 문구 | `compat-copy.js` |
| 궁합 꼭지 구성 | `compat.js` |
| TIP 문구 | `examples.js` |
| 용어 풀이 | `glossary.js` |
| 신살 | `sinsal.js` |
| 만세력 계산 | `saju.js` · `saju-data.js` |
| 갈래 아이콘 | `icons/<갈래키>.webp` |
| OG 이미지 | `og/og.html` → `node og/shot.cjs` |
| 파비콘 | `brand/favicon.svg` → `node brand/shot.cjs` |
| 약관·방침 | `_terms_body.html` · `_privacy_body.html` · `_docstyle.css` |

갈래키: `basic · newyear · money · love · biz · job · future · love2 · team`

아이콘 아홉 장 중 **신년(歲)·직업(職)·미래(運) 세 장은 제가 그린 것**입니다.
AI로 그린 메달을 새로 받으시면 같은 이름의 `.webp` 로 덮어쓰기만 하시면 됩니다.
`icons/make-missing.py` 가 그 셋을 만드는 스크립트입니다.

# 6. 올린 뒤 할 일

1. `https://내도메인/` 이 열리는지
2. `https://내도메인/og.png` 가 열리는지
3. `https://내도메인/terms.html` · `/privacy.html` 이 열리는지
4. [카카오 디버거](https://developers.kakao.com/tool/debugger/sharing)에 주소를 넣고
   **초기화** — 미리보기가 바로 반영됩니다
5. 휴대폰에서 열어 **홈 화면에 추가** 해 보기 (아이콘이 뜨면 manifest 정상)
6. [구글 서치콘솔](https://search.google.com/search-console)에 사이트 등록 후
   `sitemap.xml` 제출

# 7. 다음에 만들면 좋을 것

신년운세는 **연 1회 의식**이라 12~2월에 트래픽이 몰립니다.
구독으로 가시려면 순서가 이렇습니다.

1. **월간 처방** — 이번 달 운세가 아니라 "이번 달에 할 것 하나".
   신년운세의 12달 계산이 그대로 재료라 추가 계산이 거의 없습니다.
2. **기록** — 매달 처방을 했는지 체크 → 3개월 뒤
   "지난 분기에 3가지 중 2가지를 하셨습니다"를 보여줍니다.
   운세 앱은 갈아탈 수 있어도 자기 기록은 못 옮깁니다.

기록부터 만들면 쌓일 사용자가 없어 빈 화면만 보게 됩니다.
