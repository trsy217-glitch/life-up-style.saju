# 2. 신년운세

## 왜 토정비결과 다르게 만들었나

토정비결이 살아남은 건 **정월에 본다는 날짜가 정해져 있어서**이지 내용이 좋아서가
아닙니다. 그리고 구조적 한계가 하나 있습니다 — **예측만 주고 끝납니다.**
"3월에 구설이 있다"를 읽고 나면 할 게 없고, 맞았는지 틀렸는지도 아무도 확인하지
않습니다.

그래서 여기서는 **모든 꼭지가 "그래서 뭘 하라"로 끝납니다.**
예측이 틀리면 신뢰를 잃지만, 처방은 안 해도 손해가 없습니다.

## 들어간 것

**① 올해의 한 글자 (공유 카드)**

> 丁未 · **緩**
> 소영님의 **천천히 가는 해**
> 열리는 달 **2월·3월** / 조이는 달 **9월·10월**

십신 10종 × 순풍·역풍 = **스무 가지 글자.**
立 競 伴 分 作 緩 說 衝 流 漏 積 縮 斷 壓 位 責 悟 滯 受 息
— 876건 돌려 **20종 전부** 나오는 걸 확인했습니다.

밑에 **「문구 복사하기」** 버튼이 있습니다.

```
2027년 丁未, 나는 「緩 천천히 가는 해」
열리는 달 2월·3월 / 조이는 달 9월·10월
— LIFE-UP STYLE
```

**② 열 개 꼭지**

1. 2027년은 어떤 해인가 — 세운이 내 일간에 되는 십신, 바람 방향, 대운 교체 여부
2. **작년과 무엇이 다른가** — 재방문의 고리
3. 어느 자리가 흔들리나 — 세운 지지 × 내 네 기둥 (충·형·해·육합·삼합)
4. 열두 달 가운데 언제인가 — **12달 막대그래프**
5~8. 올해의 **돈 / 일 / 사람 / 몸**
9. **올해 할 한 가지**
10. **지금 달력에 적을 것** — 세 줄

**③ 열두 달 그래프** — 절기로 나눈 실제 월주(壬寅·癸卯…)와 점수.
좋은 두 달은 진한 금색, 조이는 두 달은 회색.

**④ 입춘 안내** — 사주의 한 해는 1월 1일이 아니라 입춘에 바뀝니다.
2027년운세는 **2027-02-04 10:46**부터입니다. 1월에 보는 사람에게는 아직 작년이라는
걸 화면에 적어 뒀습니다.

**⑤ 연도 전환 · 과금** — 올해/내년 두 버튼.
**한 글자 카드와 앞 세 꼭지는 무료**, 나머지 일곱 꼭지가 9,900원입니다.
공유되는 건 카드이고, 카드가 돌아야 사람이 들어오기 때문입니다.

# 3. 카테고리 아이콘 — 아홉 갈래 전부

**보내주신 9장은 서로 다른 그림이 6개뿐이었습니다.** (md5로 확인했고, 그 6개는
이미 들어가 있던 것과 같습니다.) 그래서 빠진 세 장은 같은 결로 직접 그렸습니다.

| 갈래 | 그림 | 출처 |
|---|---|---|
| 基 기본 | 별·길·일출 (남색) | 받은 그림 |
| 歲 신년운세 | **떠오르는 해 + 열두 달 점 (홍·호박)** | **직접 그림** |
| 財 금전 | 엽전·물결 (녹색) | 받은 그림 |
| 愛 연애 | 겹친 하트 (분홍) | 받은 그림 |
| 業 사업 | 솟는 막대·화살표 (보라) | 받은 그림 |
| 職 직업 | **열쇠 (청회색)** | **직접 그림** |
| 運 미래 | **초승달 + 퍼지는 물결 (남보라)** | **직접 그림** |
| 緣 연인궁합 | 두 사람·무한대 (분홍보라) | 받은 그림 |
| 同 비즈니스궁합 | 두 원·도시와 성장 (청록) | 받은 그림 |

## 직접 그린 세 장을 어떻게 맞췄나

받은 그림의 비율을 픽셀로 재서 구조를 똑같이 맞췄습니다.

```
바깥 금테 : 반지름의 바깥 20%  (r 0.80~1.00)
크림 바탕 : r 0.56~0.80  — 가는 금색 호 + 네 방향 금구슬
가운데 그림: r 0.00~0.56
```

색도 겹치지 않게 골랐습니다. 신년은 **홍·호박**(받은 여섯 장에 없는 색),
직업은 **청회색**(기본의 남색·비즈니스궁합의 청록과 다름), 미래는 **남보라**입니다.
30px 로 줄여도 아홉 개가 서로 구별되는지 확인했습니다.

직업만 모티프를 바꿨습니다 — 처음엔 솟는 막대로 그렸는데 **사업(業)과 똑같아져서**
열쇠로 갈았습니다. "맞는 자리를 여는 것"이고, 작아져도 윤곽이 또렷합니다.

`engine/icons/make-missing.py` 가 그 셋을 만드는 스크립트입니다.
SVG(`newyear.svg` `job.svg` `future.svg`)를 고치고 이 스크립트를 돌리면 `.webp` 가
다시 만들어집니다. AI로 그린 메달을 새로 받으시면 같은 이름의 `.webp` 로
덮어쓰기만 하시면 됩니다.

- 받은 그림: 원본 2.3MB·1254px → **원형으로 잘라 192px WebP, 장당 7~10KB**
- 원 바깥은 투명 처리 (그림의 크림색과 페이지 종이색이 미세하게 달라 그냥 쓰면 네모가 보입니다)
- `build.py` 가 data URI 로 박아 넣어 외부 이미지 요청이 없습니다
- `public/manse.html` 768KB → **802KB**

# 5. 검증

## 만들다 잡은 것

**해의 이름과 올해의 과제가 서로 반대로 나오던 문제.**
과제를 십신만 보고 고르고 있어서, "천천히 가는 해 / 벌인 것을 줄이는 해"라고 해 놓고
바로 아래 과제에는 "만들던 것을 밖으로 내보내세요"가 나왔습니다.
과제를 **십신 × 순풍·역풍 20가지**로 나눠 다시 썼습니다.

**가장 좋은 달에 "새 일은 벌이지 마세요"가 나오던 문제.**
달의 성격 문구를 열리는 달용(`do`)과 조이는 달용(`careful`)으로 갈랐습니다.

**한자 뒤 조사.** 화면에는 丁·未를 쓰는데 조사는 한글 독음(정·미)으로 정해야 합니다.
글자만 보면 받침이 없어 "未이"가 나옵니다. 보여줄 글자와 읽는 글자를 따로 받게 고쳤습니다.

**달 이름이 거꾸로.** 점수 순으로 적어서 "3월·2월"이 됐습니다. 달력 순으로 고쳤습니다.

**신년 아이콘이 화면에 안 뜨던 것.** `build.py` 의 아이콘 목록에 `newyear` 가 빠져
있어 여덟 장만 박히고 있었습니다.

**직접 그린 메달 둘레의 검은 띠.** 투명 배경 PNG 를 그대로 RGB 로 바꾸면 바깥이
검게 깔립니다. 크림색 위에 올려놓고 평탄화하도록 고쳤습니다.

# 7. 다음에 만들면 좋을 것

신년운세는 **연 1회 의식**입니다. 12~2월에 트래픽이 몰리지만 그것만으로는
구독이 안 됩니다. 구독으로 가시려면 순서가 이렇습니다.

1. **월간 처방** — 이번 달 운세가 아니라 "이번 달에 할 것 하나".
   신년운세의 12달 계산이 그대로 재료라 추가 계산이 거의 없습니다.
2. **기록** — 매달 처방을 했는지 체크 → 3개월 뒤 "지난 분기에 3가지 중 2가지를
   하셨습니다"를 보여줍니다. 6개월 쌓인 사람은 못 떠납니다. 운세 앱은 갈아탈 수 있어도
   자기 기록은 못 옮깁니다.

기록부터 만들면 쌓일 사용자가 없어 빈 화면만 보게 됩니다.

## 같이 들어간 메타 태그

`ui-manse.html` 머리에 OG·트위터 태그를 넣었습니다.

```html
<meta property="og:image" content="https://REPLACE_WITH_DOMAIN/og.png">
<meta property="og:image:width"  content="1200">
<meta property="og:image:height" content="630">
<meta property="og:url" content="https://REPLACE_WITH_DOMAIN/">
<meta name="twitter:card" content="summary_large_image">
```

**`REPLACE_WITH_DOMAIN` 을 실제 도메인으로 바꾸셔야 합니다.**
robots.txt · sitemap.xml 과 같은 자리이니 한 번에 바꾸시면 됩니다.
미리보기 이미지는 상대경로(`/og.png`)로 두면 카카오톡이 못 읽습니다.
반드시 `https://` 로 시작하는 전체 주소여야 합니다.

올리신 뒤 카카오톡에서 바로 안 바뀌면 캐시 때문입니다.
[카카오 디버거](https://developers.kakao.com/tool/debugger/sharing) 에서
주소를 넣고 초기화하시면 즉시 반영됩니다.
